Синхронизация между устройствами

Не настроено
Роль этого устройства
Выключено — устройство только получает данные с сервера: свои изменения (если есть) отправляет, но при конфликте автоматически проигрывает и без вопросов подтягивает версию с сервера. Также само периодически проверяет сервер, пока открыто.
Пароль настроек синхронизации
Без пароля это меню не откроется (долгое нажатие на облачко). Короткое нажатие пароль не спрашивает — оно просто отправляет/забирает данные согласно роли устройства.
GitHub-токен (только с правом «gist»)
ID Gist (оставьте пустым — создастся новый)
Как получить токен:
  1. Откройте github.com/settings/tokens
  2. Generate new token → Fine-grained (или classic)
  3. Права: только gist (Read and write)
  4. Скопируйте токен сюда — он хранится только в этом браузере
На каждом устройстве нужно один раз ввести тот же токен и тот же ID Gist (после первого сохранения ID появится в этом поле — скопируйте его на другое устройство).

⚠ Есть более свежие данные на сервере

Похоже, кто-то (может быть, вы же на другом устройстве) сохранил данные после вашей последней синхронизации. Чтобы ничего не потерять, выберите, что сделать с вашими текущими изменениями на этом устройстве.
Это происходит, если два устройства редактировали данные почти одновременно. Приложение не может само понять, какая версия правильная — выберите вручную.

История сохранений

Время, направление синхронизации и какие позиции добавились/удалились/изменили количество. Хранится только на этом устройстве.
